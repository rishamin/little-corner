# Little One's Haven

A soft, pastel-pink caregiver-inspired comfort website.

## Files
- `index.html` — the homepage
- `styles.css` — responsive styling
- `script.js` — reassurance messages and interactive needs cards

## Preview locally
Open `index.html` in a browser.

## Publish with GitHub Pages
1. Create a new GitHub repository.
2. Upload all three files (`index.html`, `styles.css`, `script.js`) to the repository root.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select the `main` branch and `/ (root)`, then save.
6. GitHub will provide the published website URL.

The Google Fonts import requires an internet connection. The page itself is static and does not need a server.
